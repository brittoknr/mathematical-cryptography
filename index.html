What is Cryptography?

A simple explanation behind the working model.

🔒 Encryption

Encryption changes plain text into a form that is difficult for an unauthorized person to understand. A key controls the transformation.

🔑 The Key

In a Caesar Cipher, the key is a number that tells us how many positions each letter should move in the alphabet.

🔓 Decryption

Decryption reverses the shift and converts the cipher text back into the original message.

The Mathematics Behind the Caesar Cipher

Letters, digits and common keyboard symbols rotate within separate groups using modular arithmetic.

Alphabet as Numbers

A=0, B=1, C=2, ... Z=25.

A = 0   B = 1   ...   Z = 25

Encryption

For letters, add the key K to the letter value P (mod 26). Digits and symbols rotate within their own groups.

C = (P + K) mod 26

Decryption

For letters, subtract the key K from the cipher-text value C (mod 26). Digits and symbols rotate back within their groups.

P = (C - K) mod 26

Worked Example: H → K

H has value 7. With K = 3:

C = (7 + 3) mod 26 = 10 → K

My Working Model

The physical project demonstrates the same idea using a rotating alphabet wheel, buttons, LEDs, sender and receiver boxes.

How the Model Works

The physical and digital versions follow the same basic process.

1

Enter Plain Text

The sender starts with a readable message such as HELLO.

2

Choose the Key

The wheel is set to a shift value, such as +3.

3

Encrypt

Letters, digits and common keyboard symbols rotate forward within their own groups by the selected shift. Spaces and emoji remain unchanged.

4

Decrypt

The receiver applies the reverse shift to recover the original message.
